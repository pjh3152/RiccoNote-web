RiccoNote 개인정보처리방침

시행일: 2026년 11월 20일 · 개정: 2026년 11월 20일 (웹 로그인 유지)

RiccoNote(이하 ‘앱’)는 노트와 체크리스트를 정리하는 Android 앱과 PC 웹 버전입니다. 회원가입, 광고, 사용 통계 수집 도구가 없습니다. 개발자는 사용자의 노트나 개인정보를 수집하지 않으며, 개발자 서버도 없습니다.

1. 기기에 저장되는 정보

정보저장 위치
노트의 제목·내용·체크리스트·색·라벨·고정·보관·미리알림 시각, 첨부한 사진Android 앱: 기기의 앱 전용 저장 공간
웹 버전: 사용하는 브라우저의 저장 공간
테마·보기 방식 등 설정기기 또는 브라우저의 저장 공간
휴지통의 노트7일 보관 후 정리. 그 전에 되살리거나 영구 삭제할 수 있습니다.

2. Google 드라이브 동기화 (사용자가 연결한 경우에만)

사용자가 직접 Google 계정을 연결하면, 폰과 PC가 같은 노트를 보도록 사용자 본인의 Google 드라이브를 통해 동기화합니다. 연결하지 않으면 노트는 그 기기 안에만 있습니다.

항목내용
요청하는 권한Google 로그인과 drive.appdata 하나. 이 권한은 드라이브 안의 앱 전용 숨김 폴더만 쓸 수 있으며, 사용자의 다른 드라이브 파일(사진·문서 등)은 보거나 바꿀 수 없습니다.
보내는 내용노트·라벨 데이터와 노트에 첨부한 사진
저장 위치사용자 본인의 Google 드라이브 앱 전용 숨김 폴더. 개발자는 이 데이터를 볼 수 없습니다. 사용량은 사용자의 드라이브 저장 용량에 포함됩니다.
통신 대상Google 로그인·인증 서버, Google Drive API (www.googleapis.com), 웹 버전의 로그인 연장 창구(아래). 노트 내용은 Google 드라이브로만 보냅니다.
로그인 정보비밀번호를 받거나 저장하지 않습니다. Android에서는 Google Play 서비스가 인증을 처리합니다. 웹 버전은 로그인 상태를 유지하기 위해 Google이 발급한 갱신 토큰을 암호화한 상태로 사용자의 브라우저에만 보관하고, 접근 토큰(1시간 유효)도 브라우저에 보관합니다.
로그인 연장 창구웹 버전은 Cloudflare Workers에서 동작하는 작은 프로그램(로그인 연장 창구)을 통해 Google 토큰 서버와 통신합니다. 이 창구는 로그인 코드와 암호화된 갱신 토큰을 받아 Google에서 접근 토큰을 받아 돌려줄 뿐이며, 토큰·노트·이메일 등 어떤 정보도 저장하지 않습니다. 요청을 처리하는 동안 Cloudflare가 접속 정보(IP 주소 등)를 처리할 수 있으며, 여기에는 Cloudflare의 개인정보처리방침이 적용됩니다.
연결 해제와 삭제앱에서 연결을 해제하면 드라이브 접근 권한을 철회합니다. 드라이브에 남은 데이터는 Google 계정의 드라이브 설정(앱 관리)에서 이 앱의 숨김 데이터를 지워 삭제할 수 있습니다.

Google 드라이브에 저장된 데이터에는 Google의 개인정보처리방침이 함께 적용됩니다.

3. 웹 버전 호스팅

웹 버전 화면 파일은 GitHub Pages에서 제공됩니다. 페이지를 열 때 GitHub가 접속 기록(IP 주소 등)을 처리할 수 있으며, 여기에는 GitHub의 개인정보처리방침이 적용됩니다. 노트 내용은 GitHub로 보내지 않습니다.

4. 사진, 미리알림과 Android 권한

사진은 사용자가 시스템 사진 선택기에서 직접 고른 것만 노트에 복사해 저장합니다. 사진 전체 접근 권한은 요청하지 않습니다. 미리알림은 기기 안에서 예약하고 표시하며, 알림에는 노트 제목과 내용 일부가 보일 수 있습니다. 웹 버전에서는 알림을 울리지 않습니다.

5. 백업 파일

사용자가 ‘백업 파일 내보내기’를 선택하면 직접 고른 위치에 노트가 담긴 JSON 파일을 저장합니다. 개발자는 이 파일에 접근하지 않습니다. 백업에는 노트 내용이 그대로 들어 있으니 안전하게 보관하세요.

6. 아동의 개인정보

앱은 연령과 관계없이 개인정보를 수집하지 않으며 광고·추적 기능이 없습니다.

7. 변경 및 문의

방침이 변경되면 이 페이지에 게시합니다. 문의는 GitHub Issues에 남겨 주세요. 문의에 개인정보나 실제 노트 내용을 넣지 않도록 주의해 주세요.
